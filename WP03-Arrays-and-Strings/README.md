# Practical Work N°3 — Arrays and Strings

## Overview
This practical work focuses on one-dimensional arrays in C through four exercises involving array manipulation, arithmetic operations, sorting, searching, and merging.

## Learning Objectives
- Declare, initialize, and manipulate one-dimensional arrays.
- Perform arithmetic operations on array elements.
- Calculate the scalar product of two arrays.
- Sort arrays in ascending order.
- Implement linear search and binary search.
- Merge two arrays into a single sorted array.

## Exercises

| Exercise | Description |
|---|---|
| 01 | Operations on Two 1D Arrays |
| 02 | Sort an Array into a Second Array |
| 03 | Search for the Element 3 (Three Methods) |
| 04 | Merge and Sort Two Arrays |

## Tools
- Programming Language: C
- Standard Library: `stdio.h`
- IDE: Dev-C++
