# Practical Work N°1 — Introduction to C Programming

## Overview
This practical work introduces the fundamentals of programming using the C language through five exercises.

## Learning Objectives
- Understand basic arithmetic operations.
- Practice input and output using `scanf()` and `printf()`.
- Work with integers, real numbers, and characters.
- Declare and use constants.
- Apply mathematical formulas in C.

## Exercises

| Exercise | Description |
|---|---|
| 01 | Arithmetic Operations on Two Integers |
| 02 | Arithmetic Operations on Two Real Numbers |
| 03 | Reading and Printing Four Characters |
| 04 | Surface and Perimeter of a Circle |
| 05 | Price of Pens |

## Tools
- Programming Language: C
- IDE: Dev-C++
