# Practical Work N°2 — Conditional Statements and Loops

## Overview

This practical work focuses on conditional statements and repetitive structures in C programming.

It contains 12 exercises designed to develop logical thinking, problem-solving skills, and the ability to control program execution.

## Learning Objectives

- Use conditional statements (`if`, `else if`, `else`).
- Apply the `switch` statement.
- Understand and implement loops (`for`, `while`, `do...while`).
- Perform arithmetic operations using loops.
- Work with numbers, digits, and characters.
- Solve basic mathematical problems using C.

## Exercises

| Exercise | Description | Main Concepts |
|---|---|---|
| 01 | Sign of a Number | If / Else |
| 02 | Season from Month Number | If / Else, Switch |
| 03 | Print Numbers from 0 to N | For Loop |
| 04 | Positive and Even Number | Do...While |
| 05 | Product Using Only + and - | Loops, Arithmetic |
| 06 | Prime Number | Conditions, Loops |
| 07 | Repeat Until Character is Different from * | Do...While |
| 08 | Lowercase to Uppercase | Characters |
| 09 | Largest of Three Numbers | If / Else |
| 10 | Multiplication Table | For Loop |
| 11 | Sum of Digits | While Loop, Modulo |
| 12 | Count Down to Zero | While Loop |

## Topics Covered

- Conditional Statements
- Switch Cases
- For Loops
- While Loops
- Do...While Loops
- Arithmetic Operators
- Character Manipulation
- Prime Number Testing
- Digit Processing
